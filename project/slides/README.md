# Slides — 16:9 Präsentationsvorlage

Vorlage für interne Teamsitzungen, LVR‑Termine, Recruiting‑Pitches.

## Folientypen
1. **Titelfolie** (Brand) — Markenträger‑Hintergrund, Eyebrow + großer Serif‑Titel + Meta
2. **Kapitelteiler** — Nummer in Source Serif, Titel, ruhig
3. **Eckdaten / Stats** — 4 Spalten mit großer Zahl + kurzem Label
4. **Zwei‑Spalten‑Inhalt** — H3 + Body
5. **Org / Karten** — Team‑/Personenkarten mit Avatar
6. **Vergleich** — „Sind wir / Sind wir nicht“ Side‑by‑side
7. **Großes Zitat** — Source Serif, Markenträger‑Hintergrund
8. **Closing** — wie Titelfolie, Kontaktdaten als Meta

## Bedienung
- Pfeil‑Tasten / Tap → vorwärts/zurück
- `P` → Print‑zu‑PDF Modus (jede Folie eine Seite)
- Speaker‑Notes liegen im JSON im `<head>`

## Stil‑Regeln
- Eyebrow + H2 + (optional) Lead — niemals nur Stichworte; kurze ganze Sätze
- Maximal 1 Markenträger‑Folie pro 3 normale (Sparsamkeit)
- Keine Bullet‑Listen außer in Vergleichs‑Folien
- Keine animierten Übergänge (deck-stage cuts hart — gewollt)
