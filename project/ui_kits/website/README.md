# UI Kit — Website

Marketing‑Website für BeWo imflow. Hauptaufgabe: **Vertrauen + Recruiting + Erstkontakt**.

## Komponenten
- `Header.jsx` — Sticky‑Header mit Navigation und sekundärem CTA
- `Hero.jsx` — Hero‑Sektion mit Eyebrow, H1, Lead, Doppel‑CTA, 4 Stat‑Kacheln
- `Sections.jsx` — `Leistungen`, `UeberUns`, `Teams`, `Karriere`, `CTABlock`, `Footer`
- `Contact.jsx` — Kontaktformular mit Toast‑Bestätigung

## Verhalten
- Smooth‑Scroll zwischen Sektionen über die Navigation
- Kontaktformular ist klickbar/abschickbar → Toast „Danke — wir melden uns innerhalb von zwei Werktagen.“
- Alle Buttons haben sichtbare Hover/Press/Focus‑States

## Tonalität (Beispiele bewusst gesetzt)
- Hero: „Begleitung im Alltag — auf Augenhöhe.“ + „So viel wie nötig, so wenig wie möglich.“
- Klient:innen werden gesiezt
- Keine Fachjargon‑Begriffe (FLS/BEI/PerSEH) — nur intern verwenden

## Erweiterung
- Detail‑Page für Stellenausschreibung
- News/Blog (perspektivisch)
- Unterseiten je Team mit Foto/Karte
